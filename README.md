## What AutoMacro Does

AutoMacro records mouse and keyboard activity so the same input sequence can be reproduced later. It is intended for repeatable workflows in supported desktop applications, including games and other interactive programs.

Its operation is built around a simple capture-and-replay process: record the actions once, retain the resulting macro, and play it back whenever that input pattern is needed again.

## Core Capabilities

- Capture mouse movement and button presses.
- Record sequences of keyboard input.
- Combine keyboard and mouse activity within one macro.
- Replay actions that have already been recorded.
- Repeat desktop input routines for consistent workflows.
- Use macro automation with compatible games and applications.
- Retain recorded sequences for future playback.
- Operate through a desktop-focused interface.

Select the saved macro
Start playback
